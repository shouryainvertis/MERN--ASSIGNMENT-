# Pixel & Petal Creative Studio — Landing Page

A modern, responsive landing page for a fictional creative studio. The project uses **HTML and CSS in one file**, so no separate stylesheet is required.

## Website Sections

- **Hero:** Studio name, introduction, navigation and call-to-action button
- **Services:** Brand Identity, Landing Pages and Social Media Posts
- **Gallery:** Creative workspace and design inspiration images
- **Reviews:** Two sample customer testimonials
- **Contact:** Email link and a contact form
- **Footer:** Copyright notice

## Technologies Used

- HTML5
- CSS3
  - CSS custom properties (`:root` variables)
  - Inline-block and normal document flow
  - Hover effects
  - Responsive media query for mobile screens
- Google Fonts: Playfair Display and DM Sans
- Unsplash images loaded from the internet

## Files

- `pixel-petal-creative-studio.html` — Complete website; HTML and CSS are together in this file.
- `README.md` — Project information and instructions.

## How to Run

1. Download or clone the project.
2. Open `pixel-petal-creative-studio.html` in a web browser.
3. Keep an internet connection enabled for Google Fonts and remote Unsplash images.

## Important Notes

- This is a demo landing page for a fictional creative studio. Service prices, reviews and contact details are sample content; update them before using the page for a real business.
- The contact form currently demonstrates the form layout and browser validation. It does **not** send messages until a backend or form service is connected.
- The gallery images are loaded from external Unsplash URLs, so they may not appear without an internet connection.

## What I Practised

- Building a multi-section landing page with semantic HTML
- Styling a page with CSS variables and reusable classes
- Using `inline-block`, spacing, borders and hover effects
- Adding image alternative text and form labels
- Making the layout more mobile-friendly
