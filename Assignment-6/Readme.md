# Assignment 6 - Flexbox Layouts - Chai Adda

## Main Objective
Get comfortable with one-dimensional layouts using Flexbox.

## What I Made
Made four small pages in one folder using Flexbox.

## Files
- menu.html - A simple horizontal menu bar using display: flex. Logo on left, links on right.
- login.html - A login form perfectly centred on the screen using justify-content: center and align-items: center.
- products.html - A product listing of 8 items using flex-wrap, gap and flex-grow.
- navbar-hero.html - A navbar + hero section made with flexbox. Logo on left, links on right, hero text centred using flex-direction: column.

## Flexbox Properties Used
- display: flex
- justify-content
- align-items
- flex-direction
- flex-wrap
- gap
- flex-grow

## Design Choices
Topic: Chai Adda, Bareilly - Same topic as Assignment 5 to keep the project continuous.
Colours: Dark Green #12372A for main, Cream #FBF3E4 for background, Orange #FF7A00 for buttons and highlights.
Fonts: Sora for headings and DM Sans for body text.

## What I Learned
- How to make a horizontal menu with flexbox
- How to centre any box horizontally and vertically
- How to make cards wrap with flex-wrap
- How to use gap and flex-grow for equal spacing
