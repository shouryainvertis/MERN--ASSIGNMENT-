## About the Project

Chai Adda is a tea shop landing page designed using
HTML and CSS.

The website represents a small and beautiful tea cafe
located in Civil Lines, Bareilly, Uttar Pradesh.

It provides information about the menu, gallery,
customer reviews and contact details.

## Website Sections

1. Hero Section
2. Special Menu Section
3. Gallery Section
4. Customer Reviews
5. Contact Section
6. Footer Section
