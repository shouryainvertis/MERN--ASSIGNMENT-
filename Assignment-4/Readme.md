# Siya Sharma — Portfolio Website

A responsive student portfolio website for Siya Sharma, a first-year B.Tech Computer Science and Engineering student at Invertis University, Bareilly.

## Files
- `index.html` — website structure, navigation, portfolio content, and contact form behavior.
- `style.css` — separate stylesheet with a pink-and-white theme and responsive layout.
- `siya-profile.jpg` — profile photo supplied for this portfolio.

## Sections
- Home / introduction
- About Me
- Skills: HTML, CSS, JavaScript
- Education
- Projects: Portfolio Website and HTML Form
- Contact details and message form

## Run the website
1. Keep `index.html`, `style.css`, and `siya-profile.jpg` in the same folder.
2. Open `index.html` in a browser, or enable GitHub Pages for this repository.

## Contact form note
The form validates the fields in the browser and prepares an email using the visitor's default email application (`mailto:`). It does not send messages directly or store submissions on a server.
