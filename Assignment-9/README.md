## Project Overview

Bareilly Trails is a tourism-inspired website that introduces
visitors to famous places, culture and food experiences in Bareilly.

The website has a modern pink and white design with a responsive
layout for desktop, tablet and mobile devices.

## Features

- Responsive navigation bar
- Mobile hamburger menu
- Hero section with image and buttons
- Popular places section with three cards
- Photo gallery
- About section
- Contact information
- Responsive footer

3. Open index.html using Live Server.
4. View the responsive website in your browser.
